# Trot brand assets

The identity: **phosphor terminal meets clean pixel art**. Dark surfaces, green
used as a signal rather than decoration, monospace for anything the machine says.

| File | Use |
|---|---|
| `readme-header.svg` | README hero |
| `architecture.svg` | The BLE → daemon → HTTP/WS diagram |
| `app-icon.svg` / `app-icon.png` | Application / product icon (512 px raster) |
| `github-social-preview.png` | GitHub social preview (1280×640) |
| `BRAND_GUIDE.md` | Full system: palette, type, voice, usage rules |

Palette: Ink `#050908` · Console `#0B1210` · Panel `#111A17` · Border `#24302B` ·
Phosphor `#9BF43E` · Signal `#87E939` · Text `#EAF4EC` · Muted `#91A099` ·
Warning `#FFC857`.
